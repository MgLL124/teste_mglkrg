### Teste Miguel Krug

## Descrição do projeto

Projeto desenvolvido com navegação em prompt, realiza a leitura de arquivos de texto no padrão Json e imprime com base em dois layouts disponíveis (1 e 2). Também realiza uma contagem de linhas tipadas e também a quantidade total de linhas.

## Linguagens e Frameworks

C#
.NET
Json
NUnit

## Como testar

Basta realizar um clone do projeto, abrir ele com o Visual Studio e rodar (Ctrl + F5) e utilizar os atalhos para navegar. Adicione o path de destino e o path de onde se encontra o arquivo json para poder simular. Na opção 3 apenas escolha entre layout 1 e 2.
